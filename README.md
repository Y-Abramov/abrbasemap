# ABR | CIVIL - Диспетчер карт

Тянет тайловую карту на указанную область чертежа, пересчитывает её в систему координат
чертежа и вставляет растровой подложкой под остальную графику. Нужен, чтобы под трассой,
площадкой или сетями лежала реальная местность, а не пустой лист.

## Поддерживаемые версии Civil 3D

| Civil 3D | Серия |
|---|---|
| 2015-2024 | R20.0-R24.3 |
| 2025 и новее | R25.0+ |

## Команды

| Команда | Действие |
|---------|----------|
| `BASEMAP` | Построить подложку: область, источник, зум, предпросмотр |
| `BASEMAPUPDATE` | Перекачать подложку по сохранённому заданию |
| `BASEMAPERASE` | Убрать подложку из чертежа (файл на диске остаётся) |
| `BASEMAPSETTINGS` | Настройки: узлы сетки пересчёта, таймаут, папка кэша, поиск по каталогу QMS |
| `BASEMAPABOUT` | О модуле |
| `BASEMAPCSDIAG` | Диагностика геолокации чертежа, на ленте нет |

## Система координат обязательна

Модуль пересчитывает тайлы из проекции источника в СК чертежа - без назначенной СК
он не знает, куда класть картинку. Если СК не назначена, `BASEMAP` покажет выбор из
библиотеки продукта, а назначит выбранное родной командой `MAPCSASSIGN`.

Назначает СК именно продукт, а не модуль. Причина: геолокация чертежа хранит не код,
а определение СК целиком плюс опорную точку в градусах, парную ей точку чертежа,
сближение меридианов и сетку узлов соответствия. Собирать это своими руками - тихо
получать неверную привязку, поэтому модуль только выбирает код и читает итог.

Библиотеку МСК модуль не везёт с собой и не ведёт свою: пользуется той, что установлена
в продукте. Нужной зоны нет - ставится штатными средствами Autodesk
(`MAPCSLIBRARYIMPORT`) или готовым community-сборником, модуль это только читает.

Проверить, что реально записано в чертеже, - `BASEMAPCSDIAG`: печатает все поля
геолокации, включая код СК, тип координат и опорные точки.

## Источники

Встроены четыре открытых источника: OpenStreetMap, OpenTopoMap, CyclOSM, OpenRailwayMap.
Больше модуль с собой не везёт ничего - адреса сторонних сервисов в поставку не входят.

Остальные источники приносит пользователь, двумя путями.

**Поиск по каталогу QMS.** `BASEMAPSETTINGS` → вкладка «Каталог QMS» - поиск по открытому
каталогу `qms.nextgis.com` (свыше восьмисот тайловых сервисов: кадастр, покрытия сетей,
региональные ортофото, топооснова). Для выбранной записи показываются адрес, лицензия,
условия использования и дата последней проверки каталогом. «Добавить в мои источники»
кладёт запись в личный каталог пользователя. Каталог ведёт сообщество NextGIS; ABR его
не проверяет - при первом входе на вкладку модуль об этом прямо предупреждает.

**Руками.** Файл `%AppData%\Abr\Basemap\sources.json` дополняет встроенный набор, а не
заменяет его. Поля: `urlTemplate` с подстановками `{x}`, `{y}`, `{z}`, проекция
(`Spherical` или `Ellipsoidal`), `maxZoom`, `delayMs`, `maxTilesPerRun`, `userAgent`,
`copyright`, `yOriginTop` (`false` - схема TMS, отсчёт Y снизу; по умолчанию `true`).

Кэш тайлов лежит в `%LocalAppData%\Abr\Basemap\cache` и переиспользуется между
чертежами: повторная загрузка той же местности в сеть не ходит.

## Как проходит построение

`BASEMAP` открывает одно окно, в нём всё: слева источник и уровни детальности с ценой
(тайлы, размер растра, объём), справа предпросмотр, снизу задание области.

Область задаётся кнопками «Нарисовать границу» (две точки в чертеже) или «Выбрать
объекты» (габарит выбранного плюс отступ). Окно на время указания закрывается и
открывается снова - указывать точки при открытом модальном окне AutoCAD не позволяет.
Пока область не задана, уровни детальности и ОК недоступны: считать нечего.

Предпросмотр обновляется сам при смене области и источника, кнопка рядом - принудительно.
Он качает до десятка тайлов низкого зума: это прикидка «та ли местность», а не подложка -
картинка остаётся в проекции источника и в чертёж не попадает.

По ОК скачивается и вставляется настоящая подложка.

## Что появляется в чертеже

- Растр `<имя чертежа>_basemap\<источник>-z<зум>.png` рядом с файлом чертежа, ссылка
  относительная - чертёж переносится вместе с папкой подложки.
- Файл привязки `.pgw` рядом с растром.
- Слой `ABR_Basemap`, растр уходит в самый низ порядка отрисовки.
- Задание (область, источник, зум, код СК) хранится в словаре чертежа - на нём работает
  `BASEMAPUPDATE`.

## Правовая рамка

Открытые источники (OpenStreetMap и производные) распространяются по ODbL, атрибуция
обязательна - она проставляется в чертёж вместе с растром.

**Модуль не поставляет чужие эндпоинты.** Адресов Яндекса и других коммерческих
картографических сервисов в поставке нет: их использование без API-ключа запрещено
условиями правообладателя (`yandex.ru/legal/maps_api/`, п. 3.1.1), а спутниковый слой
Яндекса не продаётся ни на одном тарифе вовсе. Модуль - средство отображения тайлов по
протоколу XYZ/TMS; какой источник подключить, решает и отвечает за это пользователь.

**Модуль не маскируется под браузер.** Все запросы уходят с одним честным User-Agent,
называющим модуль и сайт разработчика. Подмена User-Agent запрещена политикой OSM
(Tile Usage Policy, §3.4) и делает нарушение условий сервиса умышленным обходом
ограничения доступа. Свой User-Agent пользователь может задать в своём `sources.json` -
это его решение и его ответственность.

Каталог QMS ведёт сообщество NextGIS. Записи туда добавляют пользователи интернета;
ABR не проверяет их лицензионную чистоту и не отвечает за неё. Предупреждение об этом
показывается при первом входе на вкладку, согласие сохраняется в настройках.

Google Maps не поддерживается принципиально, включая обходной путь через произвольный
URL-шаблон: его условия прямо запрещают оцифровку со спутникового слоя, а это ровно
то, для чего нужна подложка в САПР.

## Известные ограничения

- Привязка пользовательского растра (GeoTIFF, выгрузка SAS.Planet) не поддерживается.
- Вектор OSM в слои чертежа не разбирается - только растр.
- Кадастровые данные НСПД не подключаются встроенно - ищутся в каталоге QMS.
- Из каталога QMS берутся только источники типа `tms` в проекциях EPSG:3857 и EPSG:3395;
  `wms`, `wfs` и `geojson` не поддерживаются.
- Ключи платных картографических API не поддерживаются.
